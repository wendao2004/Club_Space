## 几个容易问的问题

- **为什么是"内网 + 自建 CA"而不是域名 + Let's Encrypt？** 见 [部署指南](部署指南.md) 第 3 节：
  内网没有公网 DNS，DNS-01 走不通；自签 CA 是局域网里唯一稳定的 HTTPS 方案。
- **为什么不用 Postgres？** 目标机器整机 8GB，业务容器只剩 2-4GB。用 `node:sqlite` 是刻意选择，
  见 README「技术栈与关键决策」。
- **为什么没有任意命令终端？** 见 README「几个刻意的"不做"」。
- **视频在线剪辑为什么没做？** 8GB 内存与"在线剪辑"不可兼得，已降级为服务端 ffmpeg 任务接口。
