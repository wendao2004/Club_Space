# 证书分发指南（发给成员看）

> 这一段可以直接复制到社团群里发给成员。
>
> ⚠️ **部署者：发出去之前先把里面的 `<NAS 的 IP>`、`<引导页端口>`、`<主站端口>`
> 换成实际值**（分别对应你部署时填的 IP、`WL_ONBOARD_PORT`、`WL_HTTPS_PORT`），
> 然后把这句提示本身删掉。发错 IP 的后果不是"打不开"这么简单 ——
> 成员会去访问局域网里另一个恰好占着这个地址的设备。

---

## 为什么必须做这一步

社团空间部署在局域网里，用的是**自建证书**。不装根证书，浏览器会认为这个站点不安全，并且会**关掉一批功能**：

| 功能 | 不装证书时 |
|---|---|
| 摄像头 / 麦克风 / 屏幕共享 | ❌ 完全不可用 |
| 系统通知 | ❌ 不可用 |
| 剪贴板复制粘贴 | ❌ 不可用 |
| 安装成桌面应用（PWA） | ❌ 不可用 |
| 上传时的秒传加速 | ❌ 不可用（算不了文件哈希） |
| 文件浏览、上传下载、格式转换、任务 | ✅ 仍可用 |

装一次就好，之后一直有效。**手机也需要装。**

---

## 安装步骤

### 第 0 步：打开引导页

在浏览器里打开（**注意是 http，不是 https**）：

```
http://<NAS 的 IP>:<引导页端口>/onboard
```

页面会自动识别你的设备并给出对应步骤。顶部有个状态点：

- 🔴 **红色** = 证书还没装好
- 🟢 **绿色** = 已装好，会自动跳转进平台

**装之前请核对页面显示的证书指纹，和社团群里公布的保持一致**——防止有人在内网里替换证书。

---

### iPhone / iPad（最容易出错，注意有两步）

1. 点页面上的「下载并安装描述文件」→ 会提示"此网站正尝试下载一个配置描述文件"，选**允许**
2. 打开 **设置** → 顶部会看到「**已下载描述文件**」→ 点进去 → **安装**（需要输锁屏密码）
3. ⚠️ **设置 → 通用 → 关于本机 → 拉到最底下 → 证书信任设置 → 找到「社团内网根证书」→ 打开开关**

> **第 3 步千万别漏。** 只做前两步，证书是装上去了但"不被信任"，浏览器照样报不安全、功能照样不可用。大部分人卡在这里，以为装失败了。
>
> 如果「关于本机」里找不到「证书信任设置」，说明第 2 步的安装没完成，回去重做。

---

### Android

1. 点页面上的「下载 ca.crt」
2. **设置 → 安全 → 加密与凭据 → 安装证书 → 选「CA 证书」** → 选择刚下载的文件
3. 系统会弹警告说"你的数据不再私密"之类，确认继续

> **两个注意点：**
> - **必须用系统浏览器（Chrome / Edge / 三星浏览器），不要用 Firefox**。移动版 Firefox 用自己的信任库，不认系统装的证书。
> - 有些手机（华为、小米、OPPO 等）把入口藏在别处，比如「设置 → 密码与安全 → 系统安全 → 加密与凭据」。找不到就在设置里搜"证书"。

---

### Windows

1. 点页面上的「下载一键安装脚本」
2. 下载完成后，**右键 → 以管理员身份运行**（不加管理员会报权限错误）
3. 看到"安装完成"后，**完全关闭浏览器再重新打开**

> 这一步很多人做错：只按 F5 刷新是不够的。证书信任是在浏览器进程启动时加载的，必须彻底退出（任务栏也要退干净）再打开。

如果不想用脚本，也可以下载 `ca.crt` 后手动导入到「**受信任的根证书颁发机构**」存储区——注意不是「个人」，导入错了不生效。

---

### macOS

1. 点「下载 ca.crt」
2. 双击打开 → 提示加入钥匙串时选**「系统」**
3. 打开「钥匙串访问」→ 找到「社团内网根证书」→ **双击** → 展开「信任」→ 把「使用此证书时」设为 **「始终信任」** → 关闭窗口时输入密码确认

---

## 装完之后

1. 回到引导页，点「我已安装，重新检测」——状态点应该变成 🟢
2. 或者直接重新打开 `https://<NAS 的 IP>:<主站端口>/`

如果状态点还是红的：

- 重新做一遍步骤，特别注意 iOS 的第 3 步
- 完全关闭浏览器再打开（不是刷新）
- 确认没有用 Firefox（Android）
- 还是不行就找管理员，把设备型号和浏览器告诉他

---

## 常见误解

**"我点了『继续访问』就能用了"**
能打开页面，但上面表格里那些功能仍然是关闭的。因为浏览器一旦发现证书不受信任，就把这个页面标记为"非安全上下文"，而摄像头/通知这些东西**只允许在安全上下文里使用**——这不是可以绕过的限制，是浏览器的硬规则。而且 Chrome 对证书有问题的站点**禁止注册 Service Worker**，这意味着一批功能连"降级运行"都做不到。

**"装根证书会不会有安全风险"**
这个根证书只用于识别社团内网的这一台服务器，它签发的证书不能被用来冒充互联网上的任何网站。你可以随时在系统的证书管理里删掉它。不过要明白：**信任一个根证书 = 信任持有该根证书私钥的一方**。私钥就在社团的 NAS 上，所以这等于你信任社团的这台服务器——对内部平台来说这是合理的，但值得知道这一点。

**"我电脑上装了，手机还要装吗"**
要。证书是装在**设备**上的，不是装在账号上的。每台设备都要装一次。
