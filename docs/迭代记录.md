## UI 整体升级（2026-10-18）

需求：贴合 Windows 11 风格 + 自己的特色，整体干净、简洁、清爽。

做法：先开**设计评审团**——3 个子 agent 各出一套完整设计方案（Fluent 正统派 / 清爽通透派 / 降噪精修派），再由 3 个独立评委按「Win11 贴合 / 美学清爽 / 落地稳健」三套标尺盲评打分：

| 方案 | Win11 贴合 | 美学清爽 | 落地稳健 | 合计 |
|---|---|---|---|---|
| A · Fluent 正统派 | 8.8 | 8.1 | 8.1 | 25.0 |
| B · 清爽通透派 | 7.3 | 7.8 | 5.5 | 20.6 |
| **C · 降噪精修派 🏆** | 8.6 | 8.6 | 8.7 | **25.9** |

以 **C 为底**，吸收评委点名的融合项：A 的四态完备与双环焦点、B 的窗口高光边 / 任务栏双态指示 / CSS 光斑壁纸、C 的仪器面板式信息降噪。

落地内容：

- **设计令牌重写**：四层表面（画布 → 卡片 → 槽位 → 悬浮）、发丝分隔线、语义软色、字阶（18/14/13/12 + 22 等宽数字）、暗色独立成体系（强调色提亮 `#5aa9e6`）；**默认主题改为浅色优先**（没有存过偏好时默认浅色，只有系统明确偏好深色才跟随）。
- **桌面外壳**：四套 CSS 光斑壁纸（明暗各一版，零图片资源）；图标从"高饱和色块 + 白字形"改为"主色 15% 淡底 + 主色线性字形"；任务栏玻璃 + 运行双态指示（点 / 胶囊）；开始菜单"已固定"分段；窗口 8px 圆角 + 1px 高光边 + 分层阴影 + Win11 式控制按钮（关闭悬浮变红）。
- **数据页降噪**（记账最重）：列表从"一行一卡"变成"一张卡多行 + 发丝线"；分类 / 分摊 / 默认状态降为纯文字，颜色只留给金额与异常状态；行内操作默认隐身、悬浮 / 键盘聚焦才出现（触屏常显）；视图切换从实心蓝改成白底卡片式分段控件。
- **财物 / 文件 / 狼人杀**：筛选行收拢成一行、概览卡与物品卡统一 8px 圆角 + 发丝描边；文件图标底色随类型 10% 淡染；狼人杀房间卡与座位卡统一。
- **登录页与移动端**：登录页玻璃卡 + 同源光斑背景；移动端分组卡片列表、玻璃 Tab 栏、与桌面同源的图标语言。
- **顺手修掉的历史坑**：`--line / --line-subtle / --fg / --fg-dim` 这几个**被引用但从未定义**的令牌（一批边框和文字颜色其实一直没生效）补成别名；全局体检了 103 个令牌引用，只剩 3 个"动态设置 / 带兜底"的假阳性。

验证：`pnpm typecheck` 通过；全量 `node scripts/run-all-tests.mjs`：**1638 条断言全绿、0 失败**（其中 144 条是真实浏览器渲染 / 交互断言，改版后选择器契约一条没破）。改版前后各拍了一套 15 张截图（桌面 / 开始菜单 / 10 个应用 / 暗色 / 移动端 / 登录页）用于比对。

部署：已同步到 NAS `/vol1/docker/wl-club` 并 `docker compose up -d --build` 重建；

## 全系统音效（2026-10-19）

需求：给**整个系统**加上音效，参考 Windows，"让系统活起来"。上一轮只做了象棋那几种。

| # | 状态 | 做了什么 |
|---|---|---|
| 1 | 已完成 | **14 个系统音**，覆盖外壳的主要动作：启动 / 开窗 / 关窗 / 最小化 / 最大化 / 还原 / 通知 / 新消息 / 完成 / 警告 / 出错 / 点击 / 删除 / 退出登录。全部 Web Audio 现场合成，仓库里仍然**零音频文件**（版权来源说不清，体积也省了） |
| 2 | 已完成 | **音色按语义区分**，而不是所有动作共用一声"叮"：开窗上行、关窗下行、最小化下沉、最大化上抬；出错是三个短促低音（Windows「严重停止」的意思，但压低了音量）；删除是噪声下扫 + 闷响，像东西掉进回收站 |
| 3 | 已完成 | **接线在状态层**：`windows` store 的 open/close/minimize/toggleMaximize/snap/minimizeAll、`ui` store 的 notify / 右键菜单、聊天收消息、文件删除、注销、开始菜单与移动端 Tab —— 应用层不需要各自记得发声，也就不会有人漏写 |
| 4 | 已完成 | **通知音跟着 Toast 类型走**：info → 通知、success → 完成、warning → 警告、error → 出错；聊天单独用更轻的「新消息」声（一天几十条，不能像报警）。162 个 `notify()` 调用点一个没改 |
| 5 | 已完成 | **设置里加了「声音」页签**：系统音效开关、音量滑块（带感知曲线）、14 个音的试听按钮。偏好存 `localStorage`（`wl.sfx.muted` / `wl.sfx.system` / `wl.sfx.volume`） |
| 6 | 已完成 | **总闸与子开关分开**：静音是总闸（连象棋一起静），系统音效开关只管外壳 —— 有人喜欢棋子的"啪"，但不想每次开窗都响一声。棋盘上那个喇叭图标改成读同一份响应式状态，两处不会再漂移 |
| 7 | 已完成 | **防连响**：同一个音 90ms 内只响一次（开窗时 `open` 与 `focus` 是连着调的）；通知音 250ms 内只响第一声（批量删除会连弹好几条，视觉一条不少、声音只留一个）；出错不走节流 —— 静默掉一条"保存失败"比多响一声危险得多 |

刻意没做的两件：

- **不在 `restoreLayout` 里发声**：刷新页面会恢复七八个窗口，如果走 `open()` 就是一串开窗音叠在一起。恢复走的是直接塞状态，天然不发声，这一条写进代码注释里防止后人"顺手统一一下"。
- **不做 hover 声**：鼠标划过就响的系统没人受得了。

验证：`pnpm typecheck` 通过；`ui-smoke-test` **196 条断言全绿**（新增 10 条）。
声音没法用耳朵在 CI 里验，所以验的是**音频图真的被驱动了**：把 `AudioContext` 原型上的
`createOscillator` / `createBufferSource` 换成计数版，再走真实交互 ——

| 断言 | 实测 |
|---|---|
| 从开始菜单打开「设置」（开窗音） | +4 个声源 |
| 设置页有「声音」页签、开关、音量、14 个试听按钮 | 全部就位，默认开启 |
| 点「试听·启动」 | +6 个声源（2 个低音垫 + 4 个上行音，与配方一致） |
| 关闭窗口（关窗音） | +2 个声源 |
| 静音后刷新再开窗 | **0 个振荡器 / 0 段噪声**（开机音也静住了） |

## 音量可调 + 声音真的变响了（2026-10-19）

需求：声音太小，加一个调音量的功能，参考 Windows。

**先定位，再动手**：系统音的配方峰值只有 `0.04-0.11`，再乘上总增益 `0.65^1.7 ≈ 0.49`，
实际振幅只有 2%-5%；而象棋落子是 `0.18-0.34`（听起来正常）。所以问题不是"没有音量控件"，
而是**外壳音根本没给够电平**，滑块拖到 100% 也还是小。

| # | 状态 | 做了什么 |
|---|---|---|
| 1 | 已完成 | **系统音专用总线 ×3**（`SYSTEM_BUS_GAIN`）。刻意不改 14 个配方里的数字 —— 音色（各音的相对轻重）一处不动，只抬整体响度，以后想再调也只动一个常量 |
| 2 | 已完成 | **限幅器**（-3dB / 20:1，攻击 2ms）接在总音量之后。抬了电平之后多个音叠在一起会逼近满刻度，数字削顶听起来是"噗"的一声；正常音量下它几乎不动作 |
| 3 | 已完成 | **任务栏喇叭浮窗**（参考 Windows）：点托盘上的喇叭弹出，横向滑块 + 百分比 + 一键静音 + 「声音设置」直达。滚轮停在图标上直接调 ±5%；静音时拖滑块自动取消静音（Windows 的行为）；Esc 或点别处关闭 |
| 4 | 已完成 | **默认音量 0.65 → 0.8**；设置页补上「全部声音」总开关，百分比用等宽数字（拖动时不左右跳），并注明浮窗那条快捷路径 |
| 5 | 已完成 | **修掉一个一直存在的持久化 bug**：`setVolume` 存进 localStorage 的是**百分数**（`'80'`），`readVolume` 却按 0-1 的小数截断 —— 于是设过音量的用户一刷新就变成 100%，而且没人会发现。现在按百分数读，并兼容直接存小数的旧数据 |

验证：`pnpm typecheck` 通过；`ui-smoke-test` 从 **196 → 215 条断言全绿**（新增 19 条）。
音量是"看不见也听不见"的东西，所以验的是**增益节点上的真实数值**：

| 断言 | 实测 |
|---|---|
| 音频图上有 limiter | 1 个 `DynamicsCompressor` |
| 系统音总线 ×3 | 增益节点里读到 3.0 |
| 默认 80% 的曲线 | `master.gain = 0.684`（= `0.8^1.7`） |
| 拖到 40% | `setTargetAtTime` 收到 `0.211`（= `0.4^1.7`），不是只改了界面数字 |
| 浮窗 | 打开 / 显示 80% / 滑块位置 / Esc 关闭 / 「声音设置」直达页签，全部通过 |
| 静音联动 | 浮窗静音写 `wl.sfx.muted=1`；静音时拖滑块自动取消静音 |
| 浮窗位置 | 实测 `700-847px`，任务栏 `852-900px` —— 不压任务栏、不被视口裁切 |
