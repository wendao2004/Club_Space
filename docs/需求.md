# 项目需求
1. 做一个便捷化的工具、交流、上下传网站，部署在局域网的Nas中，采用dockers的方式向局域网开放端口

# 功能需求：
1.集成常用的工具：例如word转换pdf等格式转换、视频在线剪辑、在线编辑表格、等能想到的常用工具库
2.聊天功能：注册的成员可以在内网进行交流，具体功能参考飞书，主打一个搞高效办公
3.增加管理员权限：管理员可以通过命令对dockers进行最高权限的操控，如添加网站可用的软件、扩展网站的功能分支
4.记账功能：社团的报账
5.娱乐项目：狼人杀、三国杀、斗地主、象棋等主流多人娱乐项目

# 我想要的
1.这个网站用于社团中，大家可以在内网使用一些便捷的功能，复杂的业务全部可以跑在服务器上（飞牛Nas）
2.网站可以做成一个桌面的样式，操作起来最好和windows一致

# 代码架构
1.建立agent评审团，全面分析需求，最终选取最合适的技术栈
